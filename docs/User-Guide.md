# ST-BgLoader 用户使用指南

> 本文面向最终用户，按形态与任务组织操作说明。
> 所有控件名、选项值与实现一致；未实现的形态不虚构喵。

---

## 一、快速上手

### 1.1 安装
1. 将项目放入酒馆插件目录：`public/scripts/extensions/third-party/`。
2. 启动或刷新酒馆页面。
3. 在 **Extensions（扩展面板）** 找到 ST-BgLoader 卡片。

支持宿主：SillyTavern / Luker / PureTavern / TauriTavern，由单一宿主桥抹平差异喵。

### 1.2 启用
1. 在扩展卡片打开 **主开关**。
2. 状态胶囊显示「已启用」即生效（`SettingsDrawer.ts:49-53`）。
3. 点击卡片内的 **直达按钮** 打开顶栏背景抽屉。

> 主开关关闭时，插件释放对宿主背景的接管并还原原生行为（`types/index.ts:162` 注释）。

### 1.3 三处入口速记
| 入口 | 位置 | 作用 |
| :--- | :--- | :--- |
| 主开关卡片 | `#extensions_settings` 扩展面板 | 总开关、状态、直达顶栏抽屉 |
| 顶栏背景抽屉 | 酒馆顶栏背景按钮 | 媒体库与详细视听设置（媒体 / 设置双 Tab） |
| 悬浮胶囊 | 页面右下角 | BGM 播放控制（`05-miniplayer.css:10-14`） |

## 二、分形态操作

### 2.1 扩展设置抽屉形态（Extensions 卡片）
- 只呈现单主开关、状态摘要与直达按钮；不堆大段表单喵。
- 主开关：控制整体启用/停用。
- 状态胶囊：显示「已启用」或「已停用」。
- 直达按钮：一键跳转顶栏背景抽屉；停用时呈灰化（`SettingsDrawer.ts:55-58`）。

### 2.2 顶栏抽屉形态（主操作面）
抽屉保留宿主原生内容可见可用，插件面板挂载其后（增强式内嵌，`02-topbar-drawer.css:3-4`）。
- **双 Tab**（`TopbarBackgroundDrawer.ts:230-235`）：
  - 「媒体」Tab：导入区、搜索框、媒体网格、场景管理条。
  - 「设置」Tab：页面、音频、自动化、缓存、备份、云端等分组。
- **顶栏快捷区**（`:238-244`）：
  - 场景快切下拉：切换已保存场景。
  - 眼睛按钮：显示/隐藏背景。
  - 清除按钮：清除当前背景。
- 单击媒体卡片即应用为背景，双缓冲平滑过渡。

### 2.3 移动端 / 窄屏形态
- 视口 ≤1000px 时面板放开高度上限、媒体网格限高 40vh（`07-responsive.css:9-17`）。
- 视口 <450px 时网格列收为 96px、工具条折行（`:25-38`）。
- 触摸目标统一 ≥36px（`00-tokens.css:44`）；窄屏随宿主抽屉全屏接管（`:5`）。
- 各断点下的逐格差异见 [全形态 × 分辨率断点差异矩阵](Form-Factor-Matrix.md)。

### 2.4 全屏形态
- 本插件无独立全屏按钮；窄屏下由宿主把抽屉置 100dvw 实现全屏接管（`07-responsive.css:5`）。
- 插件侧仅放开自身高度上限并收敛滚动，不主动申请全屏。

### 2.5 mini 播放器形态（悬浮胶囊）
- 默认在页面右下角，仅播放时显现可配置（`05-miniplayer.css:10-30`）。
- 五个按钮（`MiniPlayer.ts:41-51`）：
  - 上一曲 / 下一曲：切换曲目。
  - 播放 / 暂停：图标随状态切换（`MiniPlayer.ts:78`）。
  - 模式：切换播放模式。
  - 曲名：最多显示 140px，超长省略（`05-miniplayer.css:75-82`）。
- 三点足够：主题中性深色胶囊，边界用边框表达，无阴影（项目 G-18 豁免）。

## 三、常见任务

### 3.1 换背景
1. 打开顶栏抽屉「媒体」Tab。
2. 导入媒体（见 3.5）。
3. 单击媒体卡片立即应用。
4. 顶栏眼睛按钮可临时隐藏背景，清除按钮可移除背景。
5. 视频首次可能因浏览器自动播放策略静音，点击页面任意处即平滑淡入声音喵。

### 3.2 设置 BGM
1. 把音频文件（`.mp3` / `.wav`）导入媒体库。
2. 单击音频卡片开始播放。
3. 在「设置」Tab 的音频分组调整：
   - **播放模式**：循环 `loop` / 单曲 `single` / 随机 `shuffle`（`types/index.ts:3`）。
   - **沉浸低通**：隔壁房间声学模拟（`TopbarBackgroundDrawer.ts:440`）。
   - **后台暂停**：切后台自动暂停（`:441`）。
   - **悬浮胶囊**：显示 mini 播放器（`:442`）；「播放时显示」仅播放时显现（`:443`）。
4. 用悬浮胶囊做播放/切歌/模式快捷键。

### 3.3 开特效
- **天气**：「设置」Tab 提供六档（`types/index.ts:94,102-109`）：
  - 关闭 / 雨水 / 飘雪 / 落樱 / 微粒 / 扫描线。
  - 可配密度、速度、透明度与风力。
- **转场**：五种效果（`types/index.ts:111`）：
  - 淡入淡出 `fade` / 缩放推进 `zoom_fade` / 柔焦 `blur_fade` / 左滑 `slide_left` / 右滑 `slide_right`。
  - 默认淡入淡出，时长 400ms（`types/index.ts:380-381`）。
- **律动频谱**：可视化模式 关闭 / 呼吸 `pulse` / 频谱 `spectrum`（`types/index.ts:110`）。
- **环境白噪音**：雨声 / 壁炉 / 风声 / 关闭（`types/index.ts:237`）。
- **景深视差**：随鼠标或陀螺仪轻微移动产生纵深感，可在设置中调节。
- 系统开启「减弱动态效果」时，插件自动移除自身过渡动效（`07-responsive.css:56-65`）。

### 3.4 场景：保存、快切、导入导出
- **应用预设**：内置预设库含赛博夜雨等场景（`types/index.ts:290-306`）。
- **快切**：顶栏场景快切下拉即可切换（`:238`）。
- **导出场景**：媒体 Tab 场景管理条的导出按钮（`TopbarBackgroundDrawer.ts:312`）导出可分享 JSON（`PublicAPI.ts:550`）。
- **导入场景**：场景管理条导入按钮选择 JSON；同 id 覆盖、其余不动，并弹窗提示新增/更新数量（`TopbarBackgroundDrawer.ts:1583-1621`）。
- **备份与迁移**：设置 Tab 备份分组的「导出 / 导入」用于整套设置 JSON（`TopbarBackgroundDrawer.ts:506-511`）；换设备时先导出再导入。

### 3.5 导入媒体
| 方式 | 操作 | 说明 |
| :--- | :--- | :--- |
| 拖拽上传 | 把文件拖入投放区 | 支持图片 / 视频 / 音频 / HTML / SVG |
| 点击上传 | 点「导入」按钮选文件 | 同上，持久化到服务端 |
| URL 导入 | 在 URL 框粘贴链接并点「导入」 | 跨域失败时走 Authority 服务端代抓取喵 |
| 批量导入 | 多选卡片后批量操作 | 支持批量删除 / 顺换 / 随机换 |

> 详细媒体格式与存储机制见 [存储架构与 Authority 集成](Storage-and-Authority-Integration.md)。

### 3.6 自动轮播 BGM
1. 在「设置」Tab 音频分组勾选「自动轮播」（`TopbarBackgroundDrawer.ts:447`）。
2. 输入轮播间隔（分钟，1–60；存储为秒，默认 300 秒，`:450-451`、`PublicAPI.ts:285`）。
3. 调整淡入淡出时长（0–2000ms，默认 800ms，`:454`、`PublicAPI.ts:286`）。
4. 约束：列表少于 2 首、未在播放、或播放模式为单曲 `single` 时不计时轮播（`types/index.ts:181-183`）。
