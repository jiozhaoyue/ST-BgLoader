## Risks

- **R-1 折叠修复的隐藏耦合**：`SettingsDrawer.render()` 会整块重建面板，任何依赖「面板只渲染一次」的假设都会被打破 → 修复须同时验证「远端设置同步 / 导入 JSON / 云端收敛」三条重渲染路径下的折叠态。
- **R-2 原生接管的版本脆弱性**：接管依赖 ST 原生 DOM 与委托事件，ST 升级可能改动 → 方案必须走**公开/稳定接缝**（捕获阶段拦截 + 原生事件），禁止 monkey-patch 模块私有函数；且必须可降级为「不接管时功能完全可用」。
- **R-3 去溢光的边界**：~~浮动迷你播放器的投影~~ 已由用户裁定「全部去掉」→ 风险消解。剩余的审美风险仅在「选中态改用边框是否够醒目」，由子任务 1 的 Dev 实测收敛。
- **R-4 文档与实现漂移**：文档任务排在最后，若前三子任务有返工则文档失效 → 文档子任务开工前重新核对 `src/` 与 `dist/` 一致性。
- **R-5 裁剪清单的越界执行**：误把「建议砍掉」当作「批准砍掉」→ 子任务 2 的实现清单中禁止出现删除类条目，删除动作单列并保持未勾选。
